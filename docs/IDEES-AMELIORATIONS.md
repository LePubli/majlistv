# Mejliss TV — idées d'améliorations et de nouvelles fonctionnalités (site)

Date : 27/10/2026. Proposées par Claude à la demande d'Epok. **Rien n'est planifié ni commencé** : chaque idée démarre sur un « go » d'Epok. Établi en lisant le code et la ROADMAP, sans avoir audité le site en ligne : ce qui est marqué « à vérifier » peut déjà exister en partie.
Effort : S = petit (≈ une étape courte) · M = moyen · L = gros chantier. Priorité : ★★★ conseillée en premier, ★★ utile, ★ plus tard.
Hors périmètre (décision d'Epok du 27/10) : applications iPhone, Android TV, Apple TV.

2. **6.2 Double authentification** : protège tout le reste.
3. **1.1 + 1.2 + 1.3 Référencement, partage d'extraits, cartes citation** : audience gratuite.
4. **1.7 E-mails de cycle de vie** + **2.2 Lettre hebdomadaire** : conversion et rétention.
5. **2.1 Notifications web** et **3.1 Cartes mémoire**.
6. **2.4 Mode podcast (RSS privé)**.
7. **4.3 Prière complète** (hégirien, Qibla, calendrier).
