# Thème Aurore (exemple)

Thème d'exemple fourni avec Mejliss TV. Copiez ce dossier, changez `id`, `name` et les fichiers, puis fabriquez le .zip :

    node api/theme-kit/build.mjs mon-theme/ mon-theme.zip
    node api/theme-kit/validate.mjs mon-theme.zip

Lisez `GUIDE-IA.md` (téléchargeable dans Admin → Apparence → Thèmes Mejliss) : il liste toutes les pages, fonctions, blocs et réglages.
